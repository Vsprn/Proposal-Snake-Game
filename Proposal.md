# Snake Game

## Repository
https://github.com/Vsprn/Proposal-Snake-Game.git

## Description
A variation on the classic snake game where if you touch certain items you get longer. If you hit yourself or a wall, you lose and have to start over. The graphics and game aspect of this are what relates it to digital art. 

## Features
- Graphics
    - Will have graphic stand in for the snake and whatever you need to touch to grow. Should probably use simple geometry to represent everything first and then replace it with images.
- Grow Feature
    - When the "snake" touches certain geometry it should grow a little in length. 
- Mouse control 
    - Snake will follow mouse cursor.
-Collision 
Feature where collision is in place. If the snake touches something the game will be lost.

## Challenges
- I need to figure out how to have an object/geometry respond to mouse movements.
- Have to figure out how to add on length to the snake.
- Need to be able to have stand in graphics that can easily be replaced. 

## Outcomes
Ideal Outcome:
- The ideal outcome would be for the snake game to function with clean graphics and the ability to replay it. 

Minimal Viable Outcome:
- Simple geometry that is able to move via the mouse and have collision with other objects. The snake should be able to grow once triggering the event for that.
